# Kho hồ sơ

Các file trong kho này là snapshot nguồn để kiểm tra provenance. Hướng dẫn đang
có hiệu lực nằm tại [WORKFLOW.md](../../WORKFLOW.md); các chủ đề nghiên cứu ở
[danh mục tài liệu](../README.md).

`guides/manifest.json` ghi đường dẫn gốc và SHA256 của hướng dẫn trước khi hợp
nhất. Các file giữ nguyên byte; liên kết tương đối bên trong phải được hiểu
theo đường dẫn gốc trong manifest. Chúng không phải hướng dẫn thực thi hiện hành.

Proof, review, preregistration, contract và run có hash vẫn ở đường dẫn evidence
gốc trong repository. [Catalog](../catalog.json) phân loại các tài liệu đó;
không nhân bản hoặc đổi byte chỉ để thay bố cục thư mục.
